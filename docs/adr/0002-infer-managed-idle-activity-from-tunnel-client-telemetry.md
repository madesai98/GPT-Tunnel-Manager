# Infer Managed idle activity from tunnel-client telemetry

Tunnel Manager will infer meaningful Managed-server activity from structured `tunnel-client` dispatcher telemetry rather than inserting itself as an MCP proxy. Managed Tunnel Runtimes may emit DEBUG-level structured telemetry internally even when the user's retained log level is INFO; lifecycle-relevant events are consumed by the supervisor while below-threshold diagnostic events are discarded instead of entering the in-memory log ring. This keeps the Manager out of the MCP data path and preserves a lightweight architecture, at the cost of treating the relevant tunnel-client telemetry schema as a compatibility surface that must be validated when promoting updates.

A newly downloaded and otherwise verified `tunnel-client` runtime may still be promoted when its activity telemetry is no longer recognized. For affected Managed Server Entries, Tunnel Manager disables idle shutdown until compatible activity detection is restored. It must never apply stale telemetry assumptions or shut down a server when activity detection is uncertain.
